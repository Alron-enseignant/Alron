L'application

Un seul outil pour tout le suivi pédagogique

Alron est une application de bureau pensée pour les enseignant·es. Elle réunit dans une interface unique la gestion des classes, les évaluations, le cahier de texte, l'agenda et une bibliothèque de générateurs d'exercices — sans dépendre d'une connexion internet.

Vos données restent uniquement sur votre clé USB : aucune information n'est transmise à un serveur. L'application propose un export complet et une suppression individuelle des données, pour rester maître de ce que vous conservez.

Un assistant virtuel, qui s'appuie principalement sur une IA locale fonctionnant hors ligne, peut vous aider à rédiger des appréciations. Vos données restent sur votre poste, et l'assistant ne remplace jamais votre jugement professionnel.

  • Gestion de classe — élèves, groupes, agenda et fiches individuelles 360°.
  • Évaluations — grilles interactives, correction assistée, export PDF.
  • Assistant d'appréciations — IA locale hors ligne, génération de synthèses toujours modifiables.
  • Cahier de texte — séances, séquences et suivi de programme.
  • Générateurs d'exercices — QCM, mots croisés, mots mêlés, textes à trous, frises, cartes muettes.
  • Espace élève — mini-jeux pédagogiques pour récompenser et motiver.

Installer Alron

Version portable pour Windows — aucune installation requise, aucune donnée transmise.

⬇ Application Alron (.zip)

Windows 10 / 11 · 64 bits Portable

Décompressez l'archive et lancez l'exécutable directement depuis votre clé USB. Un dossier de données est créé automatiquement à côté de l'application.

  1. Téléchargez l'archive alron.zip avec le bouton ci-dessous.
  2. Clic droit sur le fichier téléchargé → Extraire tout (ou double-clic selon votre navigateur).
  3. Ouvrez le dossier extrait et double-cliquez sur alron.exe.
  4. Windows affiche un écran bleu « L'ordinateur a été protégé » : cliquez sur Informations complémentaires, puis sur Exécuter quand même. Alron s'ouvre.

Pourquoi Windows affiche ce message ? Alron est une application gratuite et indépendante, développée par un enseignant plutôt que par une grande entreprise. N'étant pas passée par un certificat éditeur payant, elle est classée « non reconnue » par SmartScreen — c'est une question de statut administratif, pas un signe de danger. Des milliers d'applications gratuites et sûres déclenchent le même message. L'étape 4 ci-dessus suffit à l'ouvrir normalement.
